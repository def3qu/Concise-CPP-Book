# Appendix D - Flowcharts

Flowcharts can be useful for specifying program flow. We can use them to model program flow. Here are the basic components of a flowchart

## Basic Symbols in Flowcharts

![Table of the basic flowchart symbols, each with its name, the empty symbol, and an example: Oval (termination) with the example "Start"; Rectangle (process) with "mpg = m/g"; Diamond (decision) with "x > 0" and branches labeled No and Yes; Parallelogram (input/output) with "Enter a number:"; Arrow (flowline), which connects the other symbols.](images/appd-flowchart-symbols.png)

## Steps to Create a Flowchart

1. **Identify the Problem**
2. **Break the Problem into Steps**
3. **Choose Symbols**
4. **Connect the Symbols**
5. **Verify the Flowchart**

## Flowchart Example

Create an algorithm to allow a user to enter a number, then decide whether it is positive, negative or zero.

![Flowchart: start, then the input "Enter a number n:", then the decision "n >= 0". If no, print Negative. If yes, the decision "n == 0": if yes, print Zero; if no, print Positive. All three print steps lead to end.](images/appd-flowchart-example.png)
