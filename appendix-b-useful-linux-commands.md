# Appendix B - Useful Linux Commands

If you need help logging on, see Appendix A.

The following commands assume that you are logged in to ludwig.

| Command | Description |
| --- | --- |
| `ls` | short list of files in the current directory. Shows more files on the screen. |
| `ll` | long list of files in the current directory. Show fewer files on the screen, but has more detailed information on each file. |
| `pwd` | returns the current working directory |
| `cd dirname` | changes the working directory to dirname |

## Working with Files

| Command | Description |
| --- | --- |
| `rm filename` | remove the file called filename in the current directory |
| `cp filename1 filename2` | make a copy of `filename1` and call it `filename2` |
| `mv filename1 filename2` | rename `filename1` to `filename2` |

## Creating and using C++ programs

| Command | Description |
| --- | --- |
| `emacs file.cpp` | to create or edit the file called `file.cpp` |
| `g++ -o file.exe file.cpp` | run the g++ compiler on `file.cpp`. Make the executable file called `file.exe`. |
| `./file.exe` | run the program `file.exe` |
| `exit` | logout of the system. |
