# Appendix C - Useful Emacs Commands

| Command | Description |
| --- | --- |
| `emacs file.txt` | open file.txt. Create a new file if one does not exist |
| `Ctrl-x Ctrl-c` | exit emacs. If there are any unsaved files, you will be asked to save them. |
| `Ctrl-x Ctrl-s` | save the current file without having to exit emacs |

## Cut and Paste

| Command | Description |
| --- | --- |
| `Ctrl-k(Kill)` | to cut lines |
| `Ctrl-y(Yank)` | to paste lines |

## Navigation

| Command | Description |
| --- | --- |
| `Ctrl-a` | move to the front of line |
| `Ctrl-e` | move to the end of line |
| `Ctrl-v` | scroll down one page |
| `Ctrl-s` | search forward |
| `Ctrl-r` | search backwards |
